# 活动提示与离线截图回归

仅用于 YAB（蔚蓝档案自动化脚本）的识别和流程回归。以下路径从仓库根目录查找；维护方法面向开发者的说明在 docs/develop_doc/offline_tests.md（离线截图回归）。

## 任务入口

| 修改内容 | 先读的项目文件 |
|---|---|
| 进游戏前活动提示与公告 | core/picture.py（识别与点击）、各国际服素材目录中的坐标文件、develop_tools/test/test_main_page_popups.py（弹窗回归） |
| 批量入口、样本与诊断 | develop_tools/run_offline_tests.py（回归入口）、develop_tools/test/offline_support.py（公共回放）、develop_tools/test/fixtures/manifest.json（样本清单） |
| 商店漏项或国服已有标题样本 | 对应测试文件及清单中的使用用例；先确认是接入回归还是实际业务修改 |

## 活动提示与公告

1. 先确认截图属于进游戏前的活动提示，还是公告网页；不能用主页“小房子”特征解释这两种画面。
2. 活动提示命中左下角两种“不再显示”图标中的任意一种后，点击固定关闭位置。当前基准画面为 1280×720，关闭位置（1173，75）；右上角叉号不参与识别，实际点击沿用缩放转换。
3. 公告仍同时检查自己的工具栏和关闭特征，点击（1214，43）；不要连带改成活动提示的判定。
4. 修改后检查三种国际服素材语言及多种缩放；流程回放加入重复帧、点击未生效和真实结束画面。不要为了测试通过放宽阈值或用点击推进观测。
5. 回放中的点击只记录动作，截图才推进画面；帧已用完仍未确认结束必须失败。重复画面的点击节流与结束判断分别断言。

## 新问题的默认流程

1. 保留原截图，在样本目录增加脱敏副本，保持原尺寸与识别区域；登记来源、裁剪或遮盖范围、内容摘要、尺寸及使用用例。采集时间未知就留空，不能从文件名猜测。
2. 使用公共样本加载器和回放时钟，补识别、坐标、禁止动作及结束状态断言。完整截图、裁剪图和模拟画面在说明里区分；模拟缺项不能声称复现了真实漏检原因。
3. 新模块显式登记到回归入口，不自动搜集历史交互测试。先运行相关组，再运行全集；使用已有环境，不连接真实设备或读取账号配置。
4. 在仓库根运行 `.venv/Scripts/python.exe -B -m develop_tools.run_offline_tests`（离线全集）。用 `--suite popups`（弹窗组）选择相关组，用 `--list`（列出用例）只检查收集；列出成功不是执行通过。
5. 退出 0 才表示全集通过且零跳过；退出 1 检查断言和附件，退出 2 先修准备问题。样本缺失、摘要或尺寸错误、跳过及预期失败均不能算作通过，修复首个原因后重跑受影响组。
6. 报告写入 develop_tools/out/offline-tests（离线报告目录）的新子目录，不覆盖旧报告；失败保留最后画面、相关样本、识别区域、动作和预期结果。报告、失败目录和缓存不提交、不自动删除。

已有分组还包括 shop（商店）、drill（联合火力演习）、version（版本来源）与 infrastructure（回归基础）。国服快速战斗和扫荡确认标题样本接入公共加载器，不代表新增或修复了国服扫荡业务。回归报告只证明登记场景，不能代替实机完整流程。

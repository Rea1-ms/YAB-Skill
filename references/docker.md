# 容器构建与部署

适用于 YAB（蔚蓝档案自动化脚本）的 Docker（容器部署）构建、启动、持久化及相关排查。用户操作见项目内 deploy/docker/README_CN.md（部署说明），实现经验与验证记录见 deploy/docker/maintenance.md（容器维护说明）。

## 当前入口与范围

- 构建上下文使用项目根目录，构建文件保留在 deploy/docker/dockerfile（镜像构建文件），编排入口是 deploy/docker/docker-compose.yaml（容器编排配置）；不用复制文件或挂载整个源码目录。
- 网页、锁定依赖和识别资源在构建阶段准备；运行时直接启动服务，不拉取或强制重置项目代码，不安装依赖、不更新识别资源。
- 当前面向 Linux x86_64（常见电脑的 64 位架构）。上游识别预编译资源没有对应的 Linux ARM64（另一种 64 位架构）版本，不能仅调整基础镜像就声明支持。
- 只通过网络连接已有安卓设备，不包含安卓系统和游戏，不控制宿主机桌面窗口；宿主机模拟器自动启动保持关闭。

## 修改时保留的约定

- 后端从 uv.lock（依赖锁文件）导出后，由 uv pip sync（依赖同步命令）安装到镜像中新建的环境，校验包摘要。当前 uv 0.13.6（依赖工具版本）的 uv sync（项目同步命令）不接受构建约束文件参数；使用 uv pip sync --build-constraints（带构建约束的依赖同步命令）。旧安卓依赖的隔离构建仍需兼容 pkg_resources（旧版包元数据接口）。
- 识别程序、配套动态库和模型随固定上游提交一起准备；更新前核对当前平台和配套资源。运行镜像不需要前端构建工具。
- distribution.json（预置资源标记）使网页和识别资源复用镜像内的内容。离线识别资源检查按平台选择程序名：Windows（视窗系统）带 .exe（可执行文件后缀），Linux（服务器系统）不带；资源缺失不能变为联网下载。
- 任务配置、识别设置、识别日志和安卓授权分别使用命名数据卷，允许容器普通用户写入。重建服务保留卷，旧版项目挂载目录不自动迁移。
- .dockerignore（构建排除规则）排除本机配置、虚拟环境、嵌入识别仓库、网页本地产物、缓存和敏感文件。入口脚本固定 LF（换行格式），保留密码校验、参数传递与进程退出信号。
- 宿主机访问由 YAB_WEBUI_BIND（宿主机监听地址）和 YAB_WEBUI_PORT（宿主机映射端口）控制，服务内部保持 22267 端口。BAAS_WEBUI_TOKEN（网页访问密码）只从环境传入，时区由 TZ（时区环境变量）指定。
- 容器内的 127.0.0.1（本机回环地址）不是宿主机。host.docker.internal（宿主机访问名称）只解决主机映射，仍需调试端口可达；设备是否在线按真实调试状态确认。

## 验证与表述

健康检查从运行环境读取密码，调用真实健康接口，同时核对网页可响应、识别初始化成功且没有识别错误；仅返回成功状态码不足以标记就绪。

按改动检查既有网页运行、访问保护、设备与监听回归；修改构建时检查依赖导出、目标平台安装预检、入口脚本语法与参数传递、资源平台名和构建上下文。涉及健康判断时，用临时本机服务核对缺少或错误密码、识别等待、失败和正常就绪，不连接游戏设备。

有容器引擎时，再实际构建镜像、启动并等待健康状态，核对网页登录、容器内识别启动、设备连接和重建后的数据保留。缺少引擎时完成可做的检查，并明确镜像与设备未实跑，不把依赖预检或离线回归写成运行成功。历史通过数仅是对应实现的记录。

## 1. 完整发行流程

默认采用 Electron（桌面壳）＋可搬迁的独立 Python 3.11（运行环境）＋uv（环境管理工具）＋源码与静态资源＋离线依赖包。
`desktop/backend.spec` 和 `deploy/standalone/webui.whole.spec` 是保留的历史冻结方式，不参与当前桌面发行；不要因为旧脚本存在就恢复 PyInstaller（冻结打包工具）。

在 Windows x64（64 位视窗系统）构建，项目根目录先运行 `uv sync --python 3.11`。
进入 `desktop` 后依次运行 `pnpm install --frozen-lockfile`（按锁文件安装）、`pnpm test`（已有回归）与 `pnpm run dist`（完整发行）。
`pnpm run pack` 仅生成可解压运行的应用目录，不生成安装器。

- 维护入口是 `desktop/build.cjs`。它先准备网页，再调用 `desktop/bundle.py`，最后调用 electron-builder（桌面打包工具）；不要把忽略目录中的一次性重打脚本写成长期入口。
- 解释器版本取 `desktop/python-version`；依赖取 `uv.lock`，导出锁定版本并准备 wheel（可直接安装的依赖包）及校验清单。使用独立解释器，不复制开发虚拟环境。
- 打包前准备好网页、识别可执行程序、模型和原生 DLL（动态链接库）。构建期可联网准备；完整包首次运行必须使用内置资源离线完成准备。
- 源码运行可准备识别资源；完整发行缺少资源时明确失败，不能转为运行时下载。发行环境通过 `core/distribution.py` 判断，不能只检查 `sys.frozen`（冻结程序标记）。
- 排除用户配置、访问密码、`.env`、日志和识别资源中的嵌入 Git（版本管理工具）元数据。
- 每次构建使用独立的 `desktop/build/<本次标识>/` 和 `desktop/release/<本次标识>/`，产出 YAB 安装包与完整压缩包；旧包、失败目录和缓存保留，按用户约定处理。

### 轻量发行与工具定位

| 构建入口 | 运行准备 | 是否内置依赖管理工具 |
|---|---|---|
| `pnpm run dist`（完整发行） | 使用内置解释器和依赖离线准备 | 是 |
| `pnpm run dist:lite`（轻量发行） | 首次启动在线下载锁定解释器和依赖 | 是 |
| `pnpm run dist:lite:system`（系统工具轻量发行） | 同上，先定位或手选本地工具 | 否 |

未指定变体时沿用完整包；用户要求轻量包时默认内置工具轻量包，只有明确要求系统工具时使用第三种。三种包都保留网页、源码、识别程序与模型。共享开发配置中的“10 发包（三种安装包与压缩包）”先准备依赖和检查一次，再依次产出三种安装包及压缩包；用 `.idea/yab-tasks.ps1 -Task dist-all -Preview`（只预览命令）核对顺序，预览不代表已经构建。

- 工具来源可选内置、自动定位系统或手选文件，系统工具最低版本以 runtime-settings.cjs（设置校验）为准；路径和定位结果共用输入框，版本在旁显示。文件执行权限只属于本地设置窗口，不暴露给后端网页。
- 依赖源使用现有官方、阿里云、清华选项，仍按锁定版本和摘要安装；工具与源的选择不改变依赖身份。解释器下载不走依赖镜像；先检查已有解释器镜像和共享缓存环境变量，不能承诺切换依赖源会改变解释器来源。
- 轻量包使用第 3 版在线清单，完整包使用第 2 版离线清单。完整包不能因在线设置改变离线保证，轻量包也不能静默安装未锁定的新版本。
- 运行准备由 uv（依赖管理工具）执行；完整包构建保留 pip wheel（依赖打包命令）处理源码依赖。离线依赖缓存按导出的依赖内容和解释器版本计算，不能因只改项目版本而整批重新下载；优先复用已有共享缓存。
- 修改在线准备后，先运行桌面回归，再用 test/online-smoke.cjs（显式联网验证）在独立数据目录实际准备并启动，检查识别就绪、再次启动及环境复用；它不在默认回归中，模拟命令不能代替下载验证。


## 2. 版本、配置与品牌兼容

技能名和目录均为 `yab`，对用户显示 YAB。安装标识 `org.baas.desktop`（既有安装身份）、`BAAS_*`（兼容环境变量前缀）及仍被代码使用的内部符号按用途保留；历史项目名不等于旧技能名仍需保留。
维护时核对技能管理源目录、通用技能目录和桌面客户端的链接目标；若存在独立副本，修改后比较文件摘要，避免同名内容不一致。

二开版本取自 pyproject.toml（项目元信息），同时核对桌面与网页元信息及 uv.lock（依赖锁文件）；包内版本由构建生成，不能读取旧启动器版本或当前工作目录替代。原仓库地址、版本和完整哈希固定保存在 tool.yab.upstream（上游基准），帮助页显示短哈希并链接完整提交；没有版本库目录时仍须可用。实际对齐上游后才更新基准，不随二开版本自动变化。

发行版默认把配置放在 `YAB.exe` 同级的 `config`：

- `profiles` 保存各任务配置，`ocr` 保存识别设置，`webui.json` 保存全局网页监听设置；`YAB_CONFIG_DIR` 可覆盖配置根目录。
- 轻量包的 config/runtime-settings.json（运行设置）保存工具来源和依赖镜像，从托盘修改后下次启动使用。虚拟环境位于用户运行数据下的 runtimes/<依赖标识>/.venv（专用环境），不在安装目录。
- 运行环境、日志、浏览器状态和备份默认放在当前用户应用数据下的 `yab-desktop`（新版运行数据目录）；不自动使用原 BAAS 数据目录。`BAAS_DESKTOP_DATA`（运行数据位置环境变量）可显式覆盖位置。
- 源码启动继续沿用源码目录布局。程序旁目录不可写时明确提示；不要静默切换配置位置导致用户误以为数据丢失。

修改迁移与运行准备时，保留以下次序和约束：

1. 先校验发行清单及文件摘要，再运行任何内置工具。
2. `versions`（源码版本目录）与 `runtimes`（依赖环境目录）分开。源码变化可复用相同依赖环境，完整摘要和就绪标记都匹配才可复用；目录名使用短摘要前缀与随机后缀，避免 Windows（视窗系统）原生依赖路径过长或复用失败残留。
3. 旧配置先复制到随机待发布目录，再发布；原件保留，目标已有本地配置时优先使用目标。发布遇到临时文件占用，只针对 `EPERM/EACCES/EBUSY`（权限或占用错误）有限退避重试，持续失败时保留原数据与失败目录。
4. 版本目录的相对配置路径通过 junction（目录联接）连接共享配置。遇到 `WinError183`（目标已存在）时检查包是否混入运行配置，以及创建目录的先后顺序；不能通过删除用户配置解决。
5. 健康检查通过后才启用新版。准备或启动失败，只向使用相同配置位置的上一版本回退；无头冒烟失败必须报失败，不能把回退成功算作新版通过。
6. 环境准备完成后才开始计算后端启动的 90 秒就绪预算。

## 3. 安装目录的最终约定

用户明确要求：浏览 → 选择文件夹 → 确定之后，**原路径输入框立即显示包含 YAB 子目录的最终路径**。不加二次确认页，不加下方路径预览。

- 使用 `desktop/installer-ui.nsh` 的自定义目录页，在浏览回调中规范化路径、追加子目录并回填同一输入框；长路径滚动到末尾。
- 末级已是 YAB（大小写不敏感）、兼容旧目录名 `yab-desktop`，或目录中已有 `YAB.exe` 时不重复追加。取消浏览与返回页面不改变已有选择，也不重复套层。
- 手动编辑输入框时按完整路径使用；离开页面和开始安装时不能暗中追加目录。
- `allowToChangeInstallationDirectory: false` 是有意关闭默认目录页；默认模板会在安装阶段才追加目录。当前通过 `customPageAfterChangeDir` 插入自定义页，不要把此选项误判为禁止用户选择位置而改回去。
- `afterPack`（应用打包后钩子）生成 `installer-generated.nsh`，并把 `installer-ui.nsh`、`installer-controls.nsh` 复制到同次发行目录。修改包含关系后要验证正式安装器，而不只编译独立预览。

目录页说明和目录分组沿用参考项目的句式；名称与版本取自构建元数据，标准按钮提示取自语言包，不在译文中固定版本或另加下方预览。

当前安装器使用 NSIS（安装器工具），未切换到 Inno Setup（另一种安装器工具）；后者如被明确要求，需要单独维护脚本和升级、卸载兼容规则。

暂沿用 electron-builder（桌面打包工具）配套的定制版 NSIS（安装器工具）；当前为 3.0.4.1，准确版本以锁文件和构建日志为准。官方版本号较新不代表可直接替换配套工具链，升级需要单独验证正式安装与卸载。项目内 desktop/maintenance.md（桌面维护说明）记录具体入口与回归流程。

## 4. 暗黑模式与高分屏

- 启动时读取系统深浅色设置，并尊重高对比度；用测试宏强制深浅色验证，不修改用户系统主题。
- 分别检查标题栏、页面背景、按钮、路径框、许可富文本和进度条。深色分组标题可能忽略指定文字颜色，需要禁用该分组控件自己的主题。
- 当前安装与卸载均声明 PerMonitorV2（第二代逐屏缩放）。系统处理标准对话框和控件的缩放；插件处理缩放通知，按原始字号恢复微软雅黑及粗细，并刷新图标、侧栏、提权按钮和进度布局。只写 `ManifestDPIAware true`（启动缩放声明）不能代替这些处理。验证真实跨屏往返的字体、尺寸和图形，明确区分尺寸模拟；没有不同缩放屏幕时不宣称实测。
- 安装目录优先使用现代系统文件夹选择窗口，不可用时回退旧选择器；取消保留原值。系统选择窗口使用自己的绘制，不按普通消息框改色；本机已验证深色背景，其他系统版本、真实浅色系统及真实高对比度须另行观察，不能扩大结论。

### 素材和原生控件

- 标题、说明和顶部图标是独立静态控件，隐藏默认背景面板后仍可能保留白底；同时检查进度文字。按实际画布处理文字及背景，深色用项目颜色，浅色和高对比度用系统颜色。不能只检查大背景或图片透明度。
- 模拟高对比度时，主窗口和插件共用同一主题来源。installer-ui.nsh（界面扩展）的 yabReadHighContrast（高对比度读取宏）默认读取系统策略，回归可替换；只切插件会造成混合配色，不能当真实外观或真实高对比度实测。

- 改标志后运行 `.venv/Scripts/python.exe desktop/generate_assets.py`（素材生成命令），从主仓原图生成多尺寸图标和四倍侧栏；普通发行直接使用已保存素材。
- 语言表及 MUI（现代安装界面）标题都应检查真实字体；只有声明感知缩放不能避免位图字体或低分辨率图标模糊。侧栏用 HALFTONE（高质量缩放模式）绘制到控件实际像素尺寸。
- 圆角复选框保留原生点击、空格、焦点和勾选状态，高对比度或绘图库不可用时回退系统绘制。改动后用真实通知绘制检查像素及状态，不能只编译脚本。
- 进度状态在打包器关闭详情输出后仍用独立文字显示，同时保留原有程序运行检查；不能只加静态提示后跳过原检查。
- 普通构建使用已保存的 32 位 `desktop/assets/YabInstallUI.dll`（原生绘制插件）。修改 `desktop/native/installer-ui.cpp`（插件源码）后，先在项目根运行 `.venv/Scripts/python.exe -B desktop/build_installer_ui.py`（重建插件）；只改源码不会更新发行界面。中间文件保留在开发输出目录。
- 取消及窗口关闭复用 MUI（现代安装界面）的安装／卸载退出确认，保留标准译文、焦点、键盘和是／否返回值。系统消息框不会继承主窗口配色；在早期初始化、界面和实际安装／卸载工作线程分别启用本进程消息框绘制，覆盖单按钮及多种标准按钮，不能改其他应用或提权窗口。浅色及高对比度保留系统外观。
- 验证时实际弹出初始化及安装／卸载区段中的消息框，核对线程不同、正文和按钮区像素及原生返回值；不能只在界面定时器测试。退出确认选择“否”留在原页，选择“是”按系统取消状态退出，像素与目视结果分别记录。
- 桌面错误、说明及回退共用 message-window.cjs（应用消息弹窗），支持系统深浅色、长日志、默认焦点、取消和关闭，并核对其他窗口不能访问其消息接口；不能继续用不随主题变化的原生错误框。

### 复选框素材更新

复选框直接使用 Fluent UI System Icons（微软系统图标库）的原始矢量图。固定版本取 `desktop/assets/checkbox/manifest.json`（素材清单），许可原文保存在同目录。参考 WPF UI（桌面界面库）与 FluentIcons（图标封装库）的资源、尺寸和颜色分离方式，没有复制其代码或引入其控件框架。

1. 先读 `desktop/assets/checkbox/README.md`（素材说明），核对上游版本和三种原图；更换来源时一起更新来源记录、原图和许可。普通发行直接使用已保存素材，不联网重新抓取。
2. 仅在原图变化时，在桌面目录运行 `node generate_checkbox_assets.cjs`（素材生成命令）。它使用已有 Electron（桌面运行环境）生成三种状态、九种尺寸的透明图片、资源头文件及摘要清单，颜色由原生控件状态决定。资源内嵌插件，安装器运行时不读取外部图片。
3. 保留 `desktop/.gitattributes`（桌面换行约定）对原始矢量图和生成头文件的 LF（换行格式）限制。生成后先校验输入摘要；提交前还要检查暂存及检出过滤后的字节，避免 Windows（视窗系统）自动换行转换使重新检出后的构建失败。
4. 在项目根运行 `.venv/Scripts/python.exe -B desktop/build_installer_ui.py`（重建插件），需要已有微软桌面构建组件。摘要不符时停止编译，先核对来源、换行和清单，再重新生成；不要关闭校验。核对新插件内 27 张图片的尺寸和摘要。
5. 在桌面目录运行 `pnpm test`（桌面回归）。真实控件检查应覆盖深浅色的勾选、未勾选、禁用、按下、半选像素及点击、空格状态；焦点和无障碍仍由系统处理。高对比度、绘图库或素材不可用时使用系统绘制。记录本机缩放，不能以九种素材尺寸宣称全部缩放布局通过。
6. 回归通过后运行 `pnpm run dist`（完整发行构建），核对两种产物中的插件、原图、素材和许可与本次输入一致，再按验证与交付一节比较共同应用文件。仅改技能或文档时只检查内容及链接，不重复生成素材或打包。

仓库文档站的 `docs/develop_doc/desktop_installer.md`（桌面安装器维护）面向开发者说明上述流程；技能只保留执行约束。验证脚本若只存在于忽略的临时目录，不作为以后必须存在的维护入口。

## 5. 卸载数据选择

“保留应用数据”默认勾选；升级始终保留数据。取消勾选后才允许清理本安装目录的 `config`（配置目录），以及当前用户默认的 `yab-desktop`（新版运行数据目录）。
原 BAAS 数据目录和环境变量指定到其他位置的数据均不自动清理。

- 普通静默卸载保留数据；显式 `--delete-app-data`（删除应用数据参数）仅允许与 `/S`（静默运行参数）使用。更新时或用该参数绕过交互选择时应拒绝。
- 程序文件按本次构建的文件清单处理；不要笼统递归删除安装根目录，避免误删配置或用户新增文件。
- `uninstallerIcon.ico`（卸载显示图标）由安装器在打包后另外写入，不在应用文件清单中；生成清理脚本时在 `UNINSTALLER_ICON`（存在卸载图标的编译条件）内单独处理，再尝试非递归移除根目录。以真实生成脚本的有图标、无图标两种编译和路径日志检查，不删除文件验证。
- 成功卸载回调在正常清理之后切换到临时目录，按本次打包目录清单从深到浅重试空子目录及根目录，最多三次，全部非递归；不在用户电脑遍历安装目录，不跟随目录联接。有配置或新增文件就保留，更新时跳过。
- AppListBackup（系统开始菜单备份）是系统共享记录，不能因包含本程序的安装标识就删除整项或共享值；保留打包器正常注销快捷方式和安装身份的流程。先核对快捷方式及自有卸载项，再区分系统备份；备份中仍有标识不能单独证明应用仍安装，未证实的事件数字含义和精确写入时机不要推断。
- 卸载策略测试把删除替换为路径日志；这是策略验证，不能写成实际删除数据已经验证。遵守当前用户对文件删除的限制。

## 6. NSIS（安装器工具）的易错点

- 卸载回调调用 `un.` 前缀函数。多用户页面可能重置 `MUI_PAGE_UNINSTALLER_FUNCPREFIX`，选择安装或卸载回调时使用实际编译上下文 `__UNINSTALL__`。
- 正式编译将警告作为错误；预览和策略测试也使用 `/WX`（警告视为错误参数）。仅在对应安装／卸载构建中定义会使用的变量与函数。
- `GetFullPathName`（路径规范化指令）先写入临时变量，再赋给安装路径。输入输出直接共用 `$INSTDIR` 可能破坏值。
- 盘符根目录赋给 `$INSTDIR` 后可能失去末尾反斜线，成为 `D:`（驱动器相对路径）；先处理根目录情况，再规范化，避免解析成该驱动器的当前工作目录。
- 用 `GetOptions`（参数读取宏）传测试路径时，带短横线的目录可能被误分隔。合成路径测试使用专用环境变量。

### 页面、提权与译文

- 标准欢迎页保留名称和构建版本，正文使用标准语言包。`installer-pages.nsh`（页面状态）单独处理已接受协议及提权后恢复：仅首次跳过已接受页面，点击上一步仍能返回；初始化时尚未接受的协议不能跳过。
- 各页共用下一步按钮。每页进入前清除 `BCM_SETSHIELD`（提权盾牌状态），安装范围页再按真实条件恢复；绘制时把盾牌和文字作为一组居中，清除后恢复按钮宽度和相邻布局。回归使用真实页面回调，模拟权限状态不能算真实提权验证。
- `installer-i18n.nsh`（语言加载）与 `installer-translations/`（独立译文目录）负责自定义三语言及英文回退；业务脚本只引用词条。沿用参考项目与标准页面的文案，不随意改写；欢迎标题的名称版本来自构建元数据。
- 运行检查由安装和卸载共用。返回后按真实函数上下文恢复安装／删除状态，不能让卸载页显示“正在安装”。

### 本轮已复现的编译与绘制细节

- 部分语言缺少新增 LangString（语言字符串）时，正式编译会因警告失败；当前按语言输出中文、繁中及英文回退，保留原有语言范围。后续再遇同类问题时复核此策略，不为通过编译关闭警告。
- 当前 32 位调用接口不能按普通浮点参数传 GDI+（图形库）角度和笔宽；需要传对应单精度位模式。原写法可编译，但实际蓝色图形没有绘制；原生复选框像素检查已复现并验证修复。

## 7. 按改动验证并交付

1. 修改运行准备、迁移或安装脚本后，运行 `desktop` 中的 `pnpm test`；该入口按文件串行，避免原生预览互相改变激活状态。沿用已有 `runtime.test.cjs` 和 `installer.test.cjs`。缺少编译器缓存时相关用例会跳过，报告跳过数，不当作全部验证通过。安装策略用实际 NSIS 编译执行，删除操作替换为日志，不安装或删除真实数据。
2. 帮助文档的隐藏浏览器检查也在 `pnpm test`（桌面回归命令）内，先准备 webapp（前端目录）依赖；它不创建可见窗口。若工具沙箱报告应用容器无法读取开发运行环境，按工具权限流程在正常权限进程重跑，不关闭应用沙箱或放宽目录权限掩盖错误。
3. 路径改动覆盖已有应用目录、大小写、尾斜线、盘符根目录、取消浏览、返回和手动填写。页面改动检查提权恢复、后退及盾牌清除；主题改动检查真实退出消息框。进度改动检查原始 100%→69%、范围恢复、复制重试、显示条与文字一致、成功前不满及成功后 100%，并用小型压缩包实际执行解压和复制宏。
4. 完整发行在隔离数据目录验证首次离线启动、再次启动、识别就绪、配置复制与原件保留、修改持久化和环境复用；损坏清单、临时占用及失败恢复用已有回归验证。
5. 仅改安装器且应用内容未变时，可复用已经验证的应用目录，但仍要重新生成扩展脚本、实际编译正式安装器并生成新文件校验值。说明应用验证复用，不将旧的离线报告写成刚执行的新验证。
6. 原生插件变化后完整生成安装包和压缩包，核对安装脚本、译文、包内插件、素材及许可与源码输入一致，再逐项比较共同应用文件的摘要。当前打包器会只给安装包增加 `resources/elevate.exe`（提权辅助程序），需按本次模板核实并单独记录；其他差异必须追查，不能忽略所有差异。避免只重打安装器而继续分发含旧插件的压缩包。
7. 交付只列实际产物、验证结果和未验证边界；当前通过完整包或轻量包覆盖更新，依赖变化新建环境，尚未接入在线自动更新服务，网页的旧启动器设置不代表桌面更新已经实现。

简短汇报示例：已补齐安装卸载弹窗主题；实际线程回归与正式构建通过；应用启动沿用此前验证，系统选择窗口只记录本机实测范围。

### 回归隔离与诊断

- 原生弹窗和跨屏预览按现行串行入口运行。desktop/test/native-dialog-probe.ps1（指定窗口探测）只操作传入进程及已核实的隔离预览，使用 PrintWindow（窗口独立绘制接口）采像素，避免遮挡或裁剪；未就绪时保留失败标记并重试，不能将空画面当成功。
- 默认按钮颜色以实际原生样式为准，不按测试步骤硬编码。主题验证保留初始化和安装／卸载实际线程、真实按钮分派及返回值，不依靠切换用户前台窗口。
- 完成页的显示回调早于消息循环；等待页面就绪后在测试自身线程激活隐藏向导，再模拟取消勾选。检查“打开 YAB”默认勾选、取消后不启动及真实完成分派；启动接口替换为日志，不实际打开应用。
- desktop/test/push-settings.test.cjs（通知表单回归）使用现有 Vite（网页构建工具）接口在 develop_tools/out/onepush-ui-*（隔离输出）构建当前前端。通过 YAB_PUSH_TEST_FRONTEND（测试网页位置）交给 develop_tools/test/push_ui_server.py（隔离服务），先创建不提供网页的应用，再挂载该产物；不依赖被忽略的工作区网页，也不为测试扩大产品公共接口。
- 保留真实健康检查和 WebSocket（实时通信）表单收发，拦截外部推送。超时附当前页面、前端错误及后端日志；先查资源和服务，不只增加超时。Electron（桌面运行环境）控制台使用事件对象的 level/message（等级与消息），不继续使用已废弃的位置参数。

## 8. 桌面网页访问

桌面窗口、托盘浏览器入口和外部浏览器复用同一个服务；默认 127.0.0.1:22267，退出应用时一起停止。不要另起一套网页服务，也不要为端口冲突静默改用随机端口。

- 设置保存在程序旁的 config/webui.json（全局网页配置）；源码默认使用源码目录的同名文件，YAB_CONFIG_DIR（配置根目录）可覆盖位置。
- 桌面端 BAAS_DESKTOP_PORT（端口环境变量）和源码端显式启动参数优先于保存值；缺文件使用默认值，坏文件、非法地址或端口明确报错。保存校验必须拒绝布尔值端口。
- 页面分别显示 saved（已保存）与 active（当前运行）状态，保存后提示重启，不在任务运行时自动重启服务。
- 非回环监听仍要求 BAAS_WEBUI_TOKEN（访问密码环境变量），密码不保存到配置中。启用密码后桌面窗口和浏览器都需登录。
- 改协议后运行两端监听回归，并核实真实健康接口、认证和 WebSocket（实时通信）保存回执；验证修改配置后重启确实使用新端口。

## 9. 安装总进度与模板扩展

安装脚本按指令计数，解压插件按压缩包内容计数，并会恢复原始范围与位置；直接把二者当总百分比会出现 100% 后回到 69%。

1. 先读进度生成脚本、构建入口和原生插件。保留原控件的范围与位置供打包器使用，另用原生显示条及独立状态文字展示同一个总百分比，不重写底层计数。
2. 按准备、释放压缩包、解压、写入、保存安装信息和收尾这些实际阶段分配区间；具体数值以代码为准。这是阶段估算，不代表剩余时间。阶段内原始计数回退或复制重试时，总值只增加。
3. 切换阶段不采样上一写入方遗留的位置；范围改变后等待有效位置更新。成功前最高 99%，只有安装／卸载成功回调可以显示 100%，原始值到顶、中止或失败都不算完成。
4. installer-progress.cjs（模板扩展）将当前打包器的完整模板目录复制到本次发行的 nsis-progress（生成模板目录），只为解压插入阶段调用、为卸载初始化插入提前主题调用及编译标记。build.cjs（构建入口）切到该目录编译，并保留原包含路径、主脚本、卸载生成与签名流程。
5. 编译器先查当前目录再查包含路径，只加包含路径会被旧卸载模板遮住；生成目录保留完整上游布局，避免同名文件误用系统内置模板。正式构建定义 YAB_REQUIRE_EARLY_THEME（提前主题检查），未加载新增卸载模板时直接报错。
6. 不改依赖目录或缓存模板，不重写文件占用重试、取消与提权逻辑。插入点缺失或不唯一时停止构建并核对新模板；移除新增调用和标记后应还原上游内容，未修改的根模板逐字节一致。
7. 使用已有安装器回归验证真实控件消息和小压缩包解压复制，失败先查第一个不一致。验证后正式构建两种发行产物并核对输入及摘要；只改本文档不需要重新构建。

历史验证见项目 desktop/maintenance.md（桌面维护说明）；通过数、产物摘要和本机缩放不写成未来自动通过的依据。

## 10. 启动反馈

- 先读 desktop/startup.cjs（状态与覆盖视图）、desktop/startup-page.js（渲染与过渡）、desktop/main.js（生命周期）及对应启动回归。进度按实际阶段估算，下载或等待时不按计时器虚增，重试不回退。
- 环境准备、后端日志和识别初始化持续显示在独立启动页；日志按真实输出追加，限制大小并允许停止自动滚动。输出分段不能截断多字节字符，失败和重试保留日志及错误。
- 后端和识别就绪且主界面加载成功后，才显示 100% 并淡出覆盖页；失败不播放成功过渡。减少动态效果时直接显示主界面，渲染停止时也不能让装饰动画阻塞进入。
- 启动状态与设置接口只允许自己的本地顶层页面访问，其他窗口、后端网页和子框架不能读取日志或选择可执行文件。
- 用已有真实窗口回归检查宽窄布局、实时日志、滚动、失败重试、访问限制和实际过渡像素；记录隐藏窗口与不抢焦点预览的范围，不修改用户系统主题或动态效果设置。

## 12. 关窗轻量模式与页面提示

- 先读 desktop/window-mode.cjs（关窗状态）、desktop/main.js（主进程）、对应回归及 desktop/README.md（桌面说明）。关窗轻量模式与轻量发行包分开：前者销毁窗口释放页面，主进程、后端和任务仍运行；后者减少包内运行资源，不代表只剩核心。
- “关闭窗口时的操作”提供仅关闭窗口、开启轻量模式和询问，默认询问；提示默认勾选“下次不再提示”。选择保存到应用数据目录的 desktop-settings.json（桌面设置），取消不记住。准备未完成或其他设置、提示窗口打开时只隐藏。
- 从托盘恢复时复用后端，重建页面并恢复同源地址、窗口位置与大小；未保存输入会丢失，快速重复点击不得创建多个窗口。不承诺固定一秒内恢复或固定节省内存；用户单次测量只作为观察。此模式不改变硬件加速；普通启动未主动禁用，仅无头冒烟入口禁用。
- 工具路径、检测状态和版本共用稳定布局，“正在检查”不额外插入一行推动下方内容。设置页及网页访问页复用现有样式，宽屏短选项避免无谓换行，窄屏不溢出；用真实页面分别检查。
- webapp/src/lib/components/ToastHost.svelte（页面提示）固定在右上方，顶部倒计时条随实际时长缩短。到期时若鼠标悬停或键盘焦点仍在提示内，暂不关闭；两者离开后退出，不是重新开始倒计时。主动关闭保留，退出同时淡出、收缩高度，减少动态效果时立即切换；元素销毁清理计时和监听。
- 选用现有窗口状态、真实设置页和提示渲染回归，检查关窗选择、持久化、释放与恢复、布局及到期交互；只改文档不重复产品测试。具体检查文件按 desktop/test（桌面回归目录）当前实现定位。

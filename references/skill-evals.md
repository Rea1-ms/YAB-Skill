## 网页、配置与帮助文档核对

| 题目或输入 | 必须行为 | 不可接受的处理 |
| --- | --- | --- |
| “切到更新页后配置空了，返回还换了一份。” | 分开检查侧栏选择和配置文件；保留最近有效选择。用两份隔离配置，从非第一份往返各配置页，覆盖全局页换选与直接打开全局页；比较启动迁移完成后的用户、事件、开关文件内容。 | 把无配置目录的全局路由当作配置重置；切页发送保存或停止请求；把网页回归说成安装版已更新。 |
| “外部改了配置，网页和任务会一起更新吗？” | 分开核对每次文件读取、网页推送、任务副本和调度重读；热更新暂缓的方案保持未实现状态。 | 用读取接口每次读文件推断任务已热更新；把每日刷新或讨论方案写成现有能力。 |
| “新建配置的输入框太窄，标签和侧栏图标没了。” | 以弹窗内容区为边界检查容器与输入框，观察宽窄屏；标签与侧栏使用同一网页图标，检查静态资源过期判断和实际加载。 | 只凭构建成功判断布局；用可执行文件图标代替网页验证。 |
| “自带帮助文档白底白字。” | 在完整文档头部末尾设置独立深色画布，保留彩色强调，核对实际渲染。 | 批量改写原文档；只检查样式文本就声称可读。 |
| “桌面版也要用浏览器打开，端口在设置里改。” | 复用同一服务，保存全局设置并重启生效；端口冲突报错，局域网访问保留密码要求。 | 为浏览器另开一套服务；扩大接口权限以便测试。 |
| “首页头图已经不用了，去掉开关。” | 查找真实消费者，核对普通设置、高级页和旧配置读取；保留仍用于反序列化兼容的字段。 | 只隐藏一个入口；未查兼容读取就删字段。 |

## 识别、截图诊断与离线回归核对

| 题目或输入 | 必须行为 | 不可接受的处理 |
| --- | --- | --- |
| “活动提示关不掉，公告也要一起改吗？” | 活动提示使用左下角两种图标之一，按固定关闭坐标和缩放点击；公告保留独立工具栏与关闭特征。用后续画面确认动作完成，回放重复帧与点击未生效。 | 混用两种页面身份；依赖活动提示右上角图案；点击后直接算完成；帧耗尽仍返回成功。 |
| “把用户失败截图接入批量测试。” | 先复现实际失败，再修复并登记脱敏样本、摘要和自动断言；使用明确登记的离线入口，报告执行集和缺项。 | 连接真实设备或读取账号配置；提交原始账号画面或将原始像素复制进技能；把样本缺失、摘要错误、跳过或预期失败算作全集通过；把已有标题样本接入写成新增扫荡业务修复。 |
| “普通截图是游戏，专用截图是桌面，交换红蓝也没变。” | 先比较画面内容，再检查后台保活和显示编号；区分颜色、尺寸、截图接口和识别失败。 | 仅凭尺寸一致认定画面相同；先改颜色通道或降低主页识别阈值。 |
| “旧系统属性为空，但配置保活为真；配置解析还有报错。” | 旧属性漏检时按实例读取配置，明确字符编码；空属性与解析失败标为未知；关闭保活并重启后另行复测。报告只保留必要字段和简短错误，诊断启动脚本核对真实命令解释器与设备选项。 | 把未知当作关闭；把包含完整配置的异常报告复制进公开文档；未复测就宣称关闭保活后的效果。 |
| “替换网络回传截图后实测正常，专用截图也算修好了吗？” | 记录用户反馈及其实际验证通道；专用截图另核对，截图内容、接口失败和原生崩溃分别保留证据。 | 冒称维护者执行过网络传输；把一个通道正常推断为另一通道或内存访问冲突已修复。 |

## 商店编号与失败退出核对

| 题目或输入 | 必须行为 | 不可接受的处理 |
| --- | --- | --- |
| “漏掉第二列后，第 22 件变成下一件了。” | 固定列编号，第 22 件仍为第六行第二列；重叠行不重复计数，末行允许不足四件。 | 用识别结果压缩编号；把第 23、24 件补成第 22 件。 |
| “单点颜色漏检，能根据旁边商品补上吗？” | 仅用已有货币模板复查缺列；真实缺列保留为缺失。 | 凭邻居猜商品；把模拟漏项当作实际漏检原因已复现。 |
| “选商品或滑动一直不结束。” | 按当前规则核对连续三次缺项、空识别或滑动停滞的退出；每件最多勾选三次，一组等待上限 15 秒，期间响应停止。 | 无限重试；把模拟购买当实机购买。 |

## 发行、启动与轻量模式核对

| 题目或输入 | 必须行为 | 不可接受的处理 |
| --- | --- | --- |
| “源码能跑，给别人做完整离线包和两种轻量包。” | 完整包准备独立解释器、环境管理工具、离线依赖和识别资源；轻量包在线准备，系统工具轻量包不内置管理工具。核对锁定依赖、工具来源、缓存和运行环境目录。 | 默认恢复冻结打包或复制开发虚拟环境；把轻量包写成离线包；换下载源时改变依赖身份。 |
| “发包一次出三个安装包和三个压缩包。” | 使用共享发包配置，先预览命令顺序；比较共同应用文件、插件、素材与许可，单独说明安装器额外带的提权辅助程序。 | 提交编辑器本机元数据；把全部差异都视为可忽略，或要求压缩包具有安装器专用文件。 |
| “应用没变，只重做安装器。” | 确认应用内容未变且已有有效验证，再复用应用目录；重新生成扩展、实际编译安装器并给出新摘要，说明复用了哪些验证。 | 把旧报告写成刚完成的新验证。 |
| “改名 YAB，数据放程序旁，卸载默认保留。” | 保留安装标识和兼容环境变量；新版目录按当前规则使用，迁移保留原件，升级及外部数据目录保留。核对发行包中的当前版本与上游基准信息。 | 自动复用或清理原 BAAS 数据；无版本库时借旧启动器版本冒充基准。 |
| “启动显示进度和日志，成功后进入主界面。” | 按真实阶段更新进度，日志有界追加；服务与识别就绪且页面加载成功后完成，覆盖失败、重试和减少动态效果。 | 页面加载失败仍显示成功动画；为反馈界面放宽访问限制。 |
| “关窗进入轻量模式，提示加倒计时。” | 区分发行包与关窗模式；销毁页面时保留主进程、后端与任务，恢复时重建页面；核对持久设置、悬停、焦点和倒计时到期行为。 | 用隐藏窗口代替页面释放；等同于仅剩核心或关闭硬件加速；承诺固定恢复耗时。 |
| “构建目录删过了，测试有跳过也算通过吗？” | 分清中间文件、下载缓存、发行产物与运行数据；遵守不删除文件约定，明确缺少编译器缓存造成的验证缺项。 | 自动清理目录；把跳过计入完整安装器验证。 |

## 安装目录、原生界面与卸载核对

| 题目或输入 | 必须行为 | 不可接受的处理 |
| --- | --- | --- |
| “浏览后方框就是最终安装目录，不要再确认。” | 浏览完成后规范化并回填同一输入框；手动编辑完整路径不暗中追加。覆盖已有应用名、大小写、尾斜线、盘符根目录与取消浏览。 | 在安装时再次追加子目录；增加用户未要的预览或确认页。 |
| “主窗口暗了，取消确认框、卸载页和图标还有白底。” | 分别检查初始化、界面与实际工作线程，统一主窗口和插件主题来源；实际检查消息框译文、焦点、按钮结果及各静态控件背景。保留完整上游模板，确认正式编译使用了定制模板。 | 只验证主线程；把独立预览当真实安装；改动所有系统消息框或丢失原生返回结果。 |
| “复选框换上游素材，完成页取消勾选也要正常。” | 固定上游版本与许可，分开处理图形、颜色、尺寸；原图变更后生成素材与清单、重建插件并验证。核对真实状态、点击、空格、焦点及无障碍，高对比度或素材不可用时回退系统绘制。 | 仅验证图片；页面未就绪就点击；为预览抢用户前台；只改文档也重做发行。 |
| “跨屏后字体变了；多档位图能证明缩放通过吗？” | 核对逐屏声明、通知、原始字体与字号恢复、图标重选和布局；区分素材尺寸、模拟缩放、本机观察和真实跨屏。 | 用位图尺寸数量或模拟高对比度代替真实桌面验证。 |
| “进度到 100% 又退回；返回协议页还有盾牌。” | 保留底层计数，按阶段显示单调总值、操作文字和一致的进度条，成功回调才到 100%；按页面进入清除共享按钮盾牌，在范围页恢复真实状态。 | 把阶段估算当底层真实计数；为验证盾牌触发真实提权。 |
| “卸载后图标、空目录和共享开始菜单备份还在。” | 核对自有文件及正常注销流程；产品清理限于打包清单，成功后从深到浅有限重试空目录，不遍历或跟随联接。开发验证遵守不删除文件约定，使用路径日志并说明范围。 | 清理非空目录、旧数据或系统共享备份；推断未证实的事件数字；把策略日志当实际卸载删除验证。 |
| “素材摘要一致就可以提交吗？” | 核对原图、生成文件的换行约定，以及暂存内容和检出过滤后的字节摘要。 | 只比较工作区文件就推断提交内容一致。 |

## 桌面更新与发布核对

| 题目或输入 | 必须行为 | 不可接受的处理 |
| --- | --- | --- |
| “构建发布桌面更新，并移除旧镜像入口。” | 核对版本元信息、三个发行变体及对应清单，同版本发布后另做旧安装版跨版本验证；移除废弃活跃逻辑但保留普通源码更新，按不删除文件约定处理废弃文件。 | 推断尚未接入的分发平台或自动切源已经可用；用清单检查代替跨版本安装。 |
| “启动和进入更新页检查，失败后立即重试。” | 主界面启动完成与进入页面触发自动检查；30 秒只防自动重复，手动可立即重试，检查或下载安装进行中不重复检查。 | 检查后自动下载或安装；用自动节流阻止手动重试。 |
| “按指定时间每日检查，更新记录留程序旁。” | 定时默认关闭、默认本机 08:00，开关与时间保存在安装目录；安装结果与主程序同级，只记目标版本和完成状态，另分清更新库下载缓存。 | 改成每日首次启动、每小时轮询或每日次数上限；创建日期文件、安装包或配置备份。 |

## 技能维护、同步与提交核对

| 题目或输入 | 必须行为 | 不可接受的处理 |
| --- | --- | --- |
| “独立目录和代理目录各有新内容。” | 比较清单和内容，将有效差异合并回独立源；本机从独立技能仓库更新对应主题用例、正文和参考，检查后再同步。 | 仅凭时间覆盖；只修改安装副本；把已有主题继续写成日期批次。 |
| “目标有额外文件，客户端入口是符号链接。” | 默认先检查差异；显式同步保留额外文件、链接与版本元数据，逐文件核对分发副本和客户端读取内容，说明剩余差异。 | 删除式镜像同步；复制编辑器配置或版本库元数据；未核对就称全部一致。 |
| “把这次经验沉淀进技能。” | 提取可复用规则与最小核对题，合并同主题旧题并修正冲突；实际版本、日期、通过数和未验证范围保存在任务或项目记录。 | 将对话小结、历史通过数或每轮静态核对报告追加为技能规则；另建历史附录继续堆积。 |

## 核对方式与证据边界

1. 修改前选择对应主题题目，固定输入和通过判据，保存基线；新问题补入已有主题，重复题合并，失效规则按当前依据修正。
2. 检查头部元数据、主文长度、直接读取路径、相对引用、章节锚点、代码围栏和表格；每份参考都应能从主文直接进入。只改技能文档时不重跑无关产品构建或游戏回归。
3. 描述范围至少保留三个应加载和三个近似反例；正文核对所选题的读取路径、决策与禁止动作。静态阅读题目不算模型触发试验。
4. 独立模型、有无技能或多模型比较使用相同材料，分别记录预期、实际和纠正；未执行就标为未验证，不声称触发率或工具调用效率改善。模型提出方案不等于实际操作，正文核对不等于平台自动触发。
5. 实际执行只验证相关改动，分开记录静态检查、离线回归、真实界面、容器和实机结果；跳过、用户反馈、模拟结果与维护者实测明确区分。
6. 独立源校验后运行同步脚本，再核对文件清单、逐文件内容和客户端链接；验证结果留在当前任务记录，不追加回本文件。
